# Circulora Frontend

## Setup

Install dependencies and start the development server:

```powershell
cd frontend
npm install
npm start
```

The app opens at `http://localhost:3000`. Start the backend separately; the
frontend's API requests use `http://localhost:5000/api` by default. See
[`../backend/README.md`](../backend/README.md) for backend setup.

## Available scripts

- `npm start` starts the development server.
- `npm test` runs the Create React App test runner.
- `npm run build` creates a production build in `build/`.
